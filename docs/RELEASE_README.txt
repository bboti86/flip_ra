RA_Manager Setup Instructions
=============================

Welcome to RA_Manager! Before using the app for the first time, you need to set up your RetroAchievements account details.

1. Create a file named "settings.json" in this directory (where main.py is located). 
   (Note: The release contains an empty settings.json by default.)
2. Open settings.json in a text editor and add the following structure:

{
    "ra_username": "YOUR_RETROACHIEVEMENTS_USERNAME",
    "ra_api_key": "YOUR_RETROACHIEVEMENTS_API_KEY",
    "ra_password": "YOUR_RETROACHIEVEMENTS_PASSWORD"
}

3. You can find your API key on the RetroAchievements website under Settings > Security.
4. Save the file.
5. You're ready to launch RA_Manager!
